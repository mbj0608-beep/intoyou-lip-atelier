# 心动唇色档案 · lip atelier

INTO YOU 官方试色个人选色册，20 个不同色号、23 支口红。

## 使用

直接用浏览器打开 `index.html`。所有图片已内嵌，可离线查看；访问品牌官网、小红书和淘宝搜索需要联网。

支持手机与桌面、系列/妆效/色系筛选、色号搜索、收藏、最多三款并排对比和个人笔记。收藏与笔记只保存在当前浏览器。

## 数量

重复款：C1 × 2、N6 × 2、EM12 × 2；其他色号各 1 支。

完整色号：C1、C5、W5、N6、N3、N4、N101、VT09、VT01、OT02、AB05、GW08、W24、W08、W18、EM12、EM20、EM13、EM16、EM525。

## 来源

试色图片中 19 款来自 INTO YOU 海外官网，VT01 来自 FancyLife 商品页收录的品牌图；每款的商品页与图片地址记录在 `sources.json`，网页详情内也有来源链接。

部分色号有升级版本，网页逐款注明图片版本。VT01 使用单独标注色号的品牌模特图，并提供上唇拼图。EM 系列统一使用官方唇部近景图。品牌图可能存在光线、肤色、唇底和屏幕呈色差异。

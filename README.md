# 心动唇色档案 · lip atelier

[打开网站](https://mbj0608-beep.github.io/intoyou-lip-atelier/)

20 个色号、23 支 INTO YOU 口红的个人选色册。C1、N6、EM12 各 2 支，其余各 1 支。

## 在线版

`index.html` 与 `assets/` 一起部署到 GitHub Pages，所有展示资源均由同一个 GitHub Pages 网址提供。首次访问先显示较小的 WebP 预览图；详情和放大图按需加载。高清文件保留来源图片的原始字节，文件名带内容摘要，便于浏览器缓存。

支持手机与桌面、系列/妆效/色系筛选、色号搜索、收藏、最多三款并排对比和个人笔记。收藏与笔记保存在当前浏览器。

本地查看可使用静态 HTTP 服务器打开此目录。单文件离线 HTML 作为独立下载文件保留，不用于在线首屏。

## 来源

19 款试色来自 INTO YOU 海外官网，VT01 来自 FancyLife 商品页收录的品牌图。逐款来源见网页详情及 `sources.json`。EM 系列统一采用官方唇部近景图。

品牌图片版权归相应权利人，仅供个人选色参考。实际呈色受唇底、肤色、拍摄光线与屏幕影响。
